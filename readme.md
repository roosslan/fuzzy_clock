# Неточные часы (fuzzy clock)

Небольшое окно без рамки поверх остальных окон, показывающее время словами с точностью до пяти минут: «Без четверти два», «Половина третьего», «Ровно час». Точное время выводится во всплывающей подсказке.

Ремейк версии 2.1 от 12.01.2004 на Qt 6.

![fuzzy_clock.gif](https://github.com/roosslan/fuzzy_clock/blob/trunk/fuzzy_clock.gif?raw=true)

## Управление

- окно перетаскивается левой кнопкой мыши;
- правая кнопка открывает меню: «About», «About Qt», «Exit»;
- положение окна сохраняется в реестре, в ключе `HKEY_CURRENT_USER\SOFTWARE\rasa\FuzzyClock`.

## Сборка

Требуется Windows, Qt 6 (модуль `widgets`) и MSVC.

Сборка из командной строки разработчика Visual Studio:

```bat
qmake fuzzy_clock.pro
nmake
```

Также проект можно открыть в Qt Creator.

Для запуска на другой машине необходимо скопировать библиотеки Qt в директорию с exe:

```bat
windeployqt fuzzy_clock.exe
```

## Файлы рядом с exe

Файлы `fuzzy.conf` и `style.css` ищутся в директории, где находится `fuzzy_clock.exe`.

- `style.css` — оформление окна в синтаксисе Qt Style Sheets: `#fuzzyClockWindow` — окно, `#timeLabel` — текст.
- `fuzzy.conf` — фразы, из которых собирается время.

### Формат fuzzy.conf

INI-файл, секция `[oldstyle]`, списки внутри значения разделяются `\\`:

| Ключ | Содержимое |
|---|---|
| `minutes` | фразы; `%0` заменяется часом в именительном падеже, `%1` — в родительном |
| `minuteRefer` | 60 чисел через пробел: для каждой минуты — номер фразы из `minutes` (с нуля) |
| `nominativeHours` | 12 названий часов в именительном падеже: «час», «два», … «двенадцать» |
| `genitiveHours` | 12 названий часов в родительном падеже: «первого», «второго», … «двенадцатого» |

Для фраз с `%1` («Пять минут %1») подставляется следующий час, для фраз с `%0` («Без пяти %0») — тоже следующий, кроме минут 0–2 («Ровно %0»), где используется текущий.

При ошибке в файле (неверное количество элементов, номер фразы вне списка) вместо времени выводится «Ошибка в fuzzy.conf».
